ARENA DOS CAMPEOES - JAVA

COMO EXECUTAR
1. Abra a pasta no IntelliJ.
2. Deixe todos os arquivos .java na mesma pasta.
3. No terminal, compile com: javac *.java
4. Execute com: java ArenaCampeoes

ARQUIVOS
- Personagem.java: classe base dos personagens.
- Guerreiro.java, Mago.java e Arqueiro.java: classes dos heróis.
- Inimigo.java: classe dos inimigos e sua IA.
- ArenaCampeoes.java: controla o jogo e as batalhas.

REGRAS
- Escolha uma das três classes.
- Enfrente três inimigos.
- Em cada turno, ataque, defenda ou use uma poção.
- Comece com três poções; cada uma recupera até 20 pontos de vida.
- Vença as três batalhas para conquistar a arena.
